# Sendoff

A private, sealed group keepsake for retirements, graduations, teachers at the end of the year,
colleagues moving on, coaches at the end of a season, and anyone leaving a team.

*Kudoboard is a bulletin board. Sendoff is a sealed envelope.*

## Run the iOS app (on the Mac)

```bash
brew install xcodegen
cd ios
cp Config/Local.xcconfig.example Config/Local.xcconfig   # fill in team id; Supabase keys optional
xcodegen generate
open Sendoff.xcodeproj
```

Without Supabase keys the app runs against `MockStore`, an in-memory store seeded with a
believable retirement Sendoff, so every screen including the reveal is demoable offline.
Run the `SendoffTests` scheme to check theme contrast and store rules.

## Run the web prototype

Open `web/prototype/open.html` in a browser (or serve the folder). Tap the seal. The colored
dots at the bottom right switch themes. `contribute.html` is the page a contributor lands on.

## Set up the backend

1. Create a Supabase project. Run `supabase/migrations/0001_init.sql` in the SQL editor.
2. Enable anonymous sign-ins and email magic links in Auth settings.
3. Put the project URL and anon key in `ios/Config/Local.xcconfig`.
4. Upload stock tracks to the `stock-music` bucket as `{track_id}.m4a` (buy a royalty-free pack).
